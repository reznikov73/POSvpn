# Установщик (этап 3)

Здесь появится `posvpn-setup.iss` — по образцу `POSCloud\installer\poscloud-setup.iss`.
Пока папка содержит только требования, чтобы ничего не забыть при сборке.

## Что должен сделать установщик

1. Скопировать `posvpn-service.exe`, `posvpn-client.exe`, `wintun.dll`.
2. Установить драйвер Wintun **вложенным MSI**:
   `msiexec /i wintun.msi /qn` — апстрим не поддерживает копирование DLL
   как способ установки драйвера.
3. Зарегистрировать службу `POSvpn` (`sc create POSvpn binPath= ...`),
   тип запуска `auto`, восстановление при падении.
4. Добавить правило брандмауэра для ICMP из `10.77.0.0/16`, входящие порты
   из интернета не открывать.
5. Проверить наличие WebView2 Runtime и при отсутствии поставить Evergreen
   bootstrapper (иначе GUI покажет белое окно).
6. Создать ярлыки и ключ автозапуска для GUI (запуск свёрнутым в трей).
7. При удалении — остановить и удалить службу, снять адаптер, убрать правило
   брандмауэра, предложить сохранить `%ProgramData%\POSvpn`.

## Требования к сборке

- Go 1.27+, `-ldflags "-H windowsgui -s -w"` для GUI-процесса.
- Authenticode-подпись exe и установщика (иначе SmartScreen).
- Версия хранится в `version.txt` и подставляется в `#define MyAppVersion`.
- Inno Setup 6.7+ (для коммерческого использования — платная лицензия)
  либо WiX v6, если нужен MSI/MSM.
