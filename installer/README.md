# Установщик

`posvpn-setup.iss` — сценарий Inno Setup 6. Версия берётся из `version.txt`,
имя файла — `POSvpn-Setup-<версия>.exe`.

```powershell
# из корня проекта: сборка exe → установщик → коммит → пуш
.\release.ps1 "сообщение коммита"

# только установщик
ISCC.exe installer\posvpn-setup.iss
```

Результат: `installer\out\POSvpn-Setup-<версия>.exe` (в git не попадает).

## Что делает сейчас

1. Копирует `posvpn-client.exe`, `wintun.dll` и `posvpn-server.exe` в `{autopf}\POSvpn`.
2. Компоненты: «клиент» и «сервер» — можно поставить только нужное.
3. Ярлыки в меню «Пуск», по желанию — на рабочем столе.
4. Правило брандмауэра: входящий ICMPv4 из `10.77.0.0/16`; при удалении снимается.
5. Служба `POSvpn` (LocalSystem, автозапуск): ставится и запускается, при удалении снимается.
6. Русский и английский языки установщика.
7. Корректное удаление через список программ.

Установка требует прав администратора: файлы ложатся в Program Files, служба
и правило брандмауэра — системные. Окно после установки работает без UAC.

## Осталось на этапе 2

1. Трей и запуск свёрнутым.
2. Восстановление после сна и смены сети.
3. Recovery actions службы при падении.
4. Проверка WebView2 Runtime и Evergreen bootstrapper.
5. При удалении — предложить сохранить `%ProgramData%\POSvpn`.

## Требования к сборке

- Go 1.27+, для GUI — `-ldflags "-H windowsgui -s -w"`.
- Authenticode-подпись exe и установщика (иначе SmartScreen).
- Inno Setup 6.7+ (для коммерческого использования — платная лицензия)
  либо WiX v6, если нужен MSI/MSM.
