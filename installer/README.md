# Установщик

`posvpn-setup.iss` — сценарий Inno Setup 6. Версия берётся из `version.txt`,
имя файла — `POSvpn-Setup-<версия>.exe`.

```powershell
# из корня проекта: сборка exe → установщик → коммит → пуш
.\release.ps1 "сообщение коммита"

# только установщик
ISCC.exe installer\posvpn-setup.iss
```

Результат: `installer\out\POSvpn-Setup-<версия>.exe` (в git не попадает).

## Что делает сейчас

1. Копирует `posvpn-client.exe` и `posvpn-server.exe` в `{autopf}\POSvpn`.
2. Компоненты: «клиент» и «сервер» — можно поставить только нужное.
3. Ярлыки в меню «Пуск», по желанию — на рабочем столе.
4. Русский и английский языки установщика.
5. Корректное удаление через список программ.

## Что добавится на этапах 2–3

1. Служба `POSvpn` (`sc create`, автозапуск, восстановление при падении).
2. Драйвер Wintun **вложенным MSI**: `msiexec /i wintun.msi /qn` — апстрим
   не поддерживает копирование DLL как способ установки драйвера.
3. Правило брандмауэра для ICMP из `10.77.0.0/16`; входящие порты из
   интернета не открываются.
4. Проверка WebView2 Runtime и Evergreen bootstrapper (иначе GUI покажет
   белое окно).
5. Ключ автозапуска GUI с запуском свёрнутым в трей.
6. При удалении — снять службу и адаптер, убрать правило брандмауэра,
   предложить сохранить `%ProgramData%\POSvpn`.

## Требования к сборке

- Go 1.27+, для GUI — `-ldflags "-H windowsgui -s -w"`.
- Authenticode-подпись exe и установщика (иначе SmartScreen).
- Inno Setup 6.7+ (для коммерческого использования — платная лицензия)
  либо WiX v6, если нужен MSI/MSM.
