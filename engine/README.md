# engine

Общий модуль клиента и сервера. Никаких внешних зависимостей — только
стандартная библиотека.

| Файл | Что внутри |
|---|---|
| `protocol.go` | типы сети, узла, карты сети, запросов и ответов API |
| `ipam.go` | подсети `10.77.<номер>.0/24`, выдача свободного адреса |
| `secret.go` | PBKDF2-пароли, токены узлов, короткие идентификаторы |
| `keys.go` | пара ключей X25519, проверка публичного ключа |

`go test ./...` — 9 тестов: адресация, границы подсети, пароли, токены, ключи.
