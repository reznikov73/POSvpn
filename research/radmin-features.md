## 1. Что делает продукт

**[П]** «Radmin VPN is a free and easy-to-use software product to create virtual local networks. The program allows users to securely connect computers, located behind firewalls» — главная страница.

Состав функций (все пункты — из официальных страниц и скриншотов):

1. **Создание сети** — кнопка «Create Network», поля «Network name» и «Password», кнопка «Create». **[П]** (`radmin-vpn.com/help/`, RU-версия: «Укажите желаемое имя сети и задайте пароль»).
2. **Два типа сетей** — вкладки **Private Network** и **Gaming Network**. Приватная присоединяется по имени+паролю; игровая выбирается из списка игр (поиск по названию, счётчик участников). **[П]** (скриншоты `help-1-4.png`, `help-1-6.png`).
3. **Вход по имени и паролю** — «Join Network» → имя сети + пароль. **[П]**
4. **Участники** — сеть раскрывается в списке, внутри — узлы с индикатором качества канала; в текущей версии есть отдельная вкладка «Members» и столбцы, включая «IP address», «Status», «Channel type», «Network Adapter». **[П-стр]** (`Members`, `Channel type:`, `Network Adapter`, `Username`, `IPv6`).
5. **Права в сети** — роли «администратор» и «пользователь», выдача/отзыв прав администратора, блокировка участника, ограничение пользователя. **[П-стр]** (`Grant Admin Rights`, `Revoke admin rights`, `Block user`, `Restricted user`; RU: «Отозвать права администратора», «Заблокировать пользователя», «Ограничить пользователя»).
6. **Управление сетью** — переименование, смена пароля, удаление, выход, включение/отключение сети, состояние Online/Offline, закрытие сети для новых участников. **[П-стр]** (`Change Name`, `Change password`, `Delete Network`, `Leave Network`, `Enable/Disable network`, `The network is closed to new members; joining is impossible`).
7. **Чат внутри сети** — текстовые сообщения, ответы, пересылка, редактирование, жалобы на сообщение/пользователя, блокировка, индикатор «печатает», смайлики; журналы чата в папке `Chatlogs`. **[П-стр]** (`%1 is typing`, `Report message`, `Chatlogs` в таблице MSI).
8. **Интеграция с Radmin (remote control)** — из контекстного меню участника: установить Radmin Server, открыть режимы Radmin (полное управление, только просмотр, передача файлов, голосовой чат). **[П-стр]** + **[П]** (help: «Radmin → Управление» в контекстном меню).
9. **Проверка связи** — ping из контекстного меню и индикатор из 4 «палочек» + состояние «disconnected». **[П-стр]** (`ping_1bar…ping_4bar`, `ping_disconnected`; RU-строка «Пинг»).
10. **Копирование адреса** — «Copy IP address», «Copy IPv6 address», «Copy Network Name». **[П-стр]**
11. **Автообновление** — «Radmin VPN can install its updates automatically» **[П]**; в сборке есть `RvDownloader.dll`, `RvRolUpdater.dll`, пункт «Обновить программу до последней версии». **[П-стр]**
12. **Прокси** — настройка «Use a proxy server», адрес прокси, состояние «Connecting via your configured proxy». **[П-стр]**
13. **Мультиязычность** — 100+ файлов переводов `.qm` (включая `ru_RU`). **[П]**
14. **Аккаунт/профиль** — в UI присутствуют «Profile», «Personal data», «Registration…», «Authorization failed». Назначение (обязательность регистрации) не подтверждено. **[П-стр]**, статус требования — **не проверено**.

## 3. IP-адресация

- **Диапазон: `26.0.0.0/8`.** Подтверждено дважды: (а) правило брандмауэра, которое ставит установщик: `netsh advfirewall firewall add rule name="Radmin VPN icmpv4" … remoteip=26.0.0.0/8 protocol=icmpv4`; (б) официальная инструкция по Kaspersky: «в столбце Тип сети установить Доверенная сеть, в строчке 26.0.0.0/8». **[П]**
- **Собственный адрес** отображается в главном окне рядом с именем ПК: на официальном скриншоте — `26.31.167.174`, статус «Online». **[П]**
- В ресурсах встречаются `26.0.0.54` и маска ввода `26.000.000.000` — адрес вводится/показывается в формате с ведущими нулями по октетам. **[П-стр]**
- **Конфликты адресов обрабатываются явно**: сообщение «Address conflict detected for IP address %1», класс `CIpAddressConflictToast`; отдельно есть `CIpAddressRenewedToast` и `TClientIpAddress`. **[П-стр]**
- **Статичность**: адрес выдаётся автоматически и в рамках сети выглядит постоянным для узла, но доказательства «жёстко закреплён за ПК навсегда» нет; наличие toast «address renewed» означает, что перевыдача возможна. Формулировка для спецификации: **адрес назначается координатором, стабилен в пределах сети, при конфликте — обработка и перевыдача**. Уровень: **[П-стр]** для механизмов, **[Г]** для гарантии стабильности.
- **IPv6** поддерживается на уровне UI (копирование IPv6-адреса, столбец IPv6). Механика выдачи не проверена.

## 5. Обход NAT и релей

- **[П]** Официальный help: «A **Relay/TCP** connection is established when a direct connection cannot be established. … If most of the connections … are Relay/TCP, then the reason … is most likely on your Internet provider side. Getting a public IP address … may help». То есть: сначала пробуется **прямое** соединение, при неудаче — **релей через TCP**; релей не требует проброса портов, но зависит от провайдера (симметричный NAT/CGNAT увеличивает долю релея).
- **[П-стр]** В UI есть столбец/подпись **«Channel type:»** со значениями «Direct» и «Relay», а также счётчики «%n direct channels» / «%n relay channels» — тип канала показывается по каждому участнику и суммарно.
- **[П-стр]** В `RvROLClient.dll` присутствуют классы коннекторов: `CDirectEnetConnector`, `CENETConnector`, `CTcpInConnector`, `CUniversalConnector`, `CTRSConnector`; в службе — строка `TcpRelay`. Это подтверждает архитектуру «прямой UDP-канал (ENet) + TCP-релей как резерв».
- **[Г]** Релей — общий сервис Famatech (не клиент-клиент), трафик идёт через инфраструктуру вендора; при недоступности релея соединение не устанавливается.
- **Проброс портов не требуется** — продукт заявлен как решение «behind firewalls you don't control». **[П]**

## 6. Шифрование и аутентификация

- **[П]** Страница безопасности: «Radmin VPN uses **end-to-end 256-bit AES** encryption». Это маркетинговое утверждение; независимой проверки нет.
- **[П]** Там же: политика «no logging» — не логируются трафик и персональные данные; хранится минимум служебных данных.
- **[П]** В составе есть OpenSSL 3 (`libcrypto-3.dll`, `libssl-3.dll`) и `libcurl` → управляющий канал, вероятно, поверх TLS. **[П]** для наличия библиотек, **[Г]** для их роли.
- **Аутентификация в сети** — по имени сети и паролю. Ошибки: «Invalid network name or password», «Password must be at least %1 characters long», «Passwords don't match», «Cannot connect to ROL server», «ROL protocol error», «Authorization failed». **[П-стр]**
- **Пароль сети** хранится/проверяется на стороне сервиса (сообщения «Сервер недоступен, попробуйте позже», «Потеряно соединение с сервисом»). **[П-стр]**
- **Встроенный firewall игровых сетей**: «Radmin VPN's Gaming Networks have a built-in firewall which is always turned on, in order to prevent access to common Windows services such as shared folders within a Gaming Network». **[П]**

## 7. Служба Windows, автозапуск, трей

- **Служба**: имя `RvControlSvc`, отображаемое имя **«Radmin VPN Control Service»**, запуск от `.\LocalSystem` (таблица `ServiceInstall` в MSI). Исполняемый файл `RvControlSvc.exe`. **[П]**
- **GUI отдельно от службы**: `RvRvpnGui.exe` (Qt5/QML), стартер `RvGuiStarter.exe`. **[П]**
- **Автозапуск**: установщик пишет в `Software\Microsoft\Windows\CurrentVersion\Run` значение `"<install>\RvRvpnGui.exe" /minimized` → GUI стартует при входе пользователя **свёрнутым**. **[П]**
- **Трей**: в ресурсах есть иконки `:/tray/online.svg` и `:/tray/offline.svg`, используется `QSystemTrayIcon`, поддерживается старт с ключом `/minimized`. **[П-стр]** Поведение при нажатии на крестик (минимизация вместо выхода) строкой не подтверждается — **[Г]**.
- **Состояние службы в UI**: «Service not started» + красная круглая кнопка запуска («Нажмите круглую кнопку в Radmin VPN, чтобы запустить сервис»). **[П]**
- **Драйвер**: `RvNetMP60.sys` (NDIS), устанавливается через `drvinst32/64/arm64`, INF `NetMP60_1_1_*.inf`, DriverVer `08/11/2022, 15.39.54.8`. **[П]**

## 10. Порты и брандмауэр

- **[П]** Официальная документация **не публикует** номера портов для Radmin VPN. Help требует не «открыть порты», а **разрешить приложение** в стороннем firewall/антивирусе (инструкции для Avast, Dr.Web, ESET, Kaspersky, McAfee, Norton) и добавляет адаптер `Famatech Radmin VPN Ethernet Adapter` в доверенную сеть.
- **[П]** Установщик сам создаёт правило: входящий **ICMPv4 разрешён только с `26.0.0.0/8`**, имя правила «Radmin VPN icmpv4». Дополнительно установщик вызывает `RvAddServiceFirewallException` для `RvControlSvc.exe` — это исключение **по приложению**, а не по номеру порта.
- **[Г]** Из этого следует: ping внутрь виртуальной сети разрешён, отдельные порты вручную не открываются; какие именно порты открывает исключение для службы — не проверено.
- **[П-стр]** В службе есть строка `TcpRelay` → релей работает по TCP; конкретный порт **не проверен**.
- **Вывод для спецификации**: клиенту достаточно **исходящих** соединений; входящие порты открывать не нужно, кроме ICMP от адресов виртуальной сети. **[П]** для принципа, **[Г]** для конкретных номеров портов.
- Отдельно: у Radmin (remote control) default port **4899** — это не Radmin VPN, не путать. **[П]** (`helpdesk.radmin.com`).

## 11. Смена сети, сон, гибернация

- **[П-стр]** В коде есть классы `rvpn::CNetworkChanges` / `QNetworkChanges` — клиент подписан на изменения сетевой конфигурации Windows и реагирует на них (переподключение каналов).
- **[П-стр]** Есть состояния «Service connection lost», «Waiting for adapter response...», циклические «Connecting...» — то есть разрыв и восстановление связи являются штатным сценарием с явной индикацией.
- Точный сценарий (переустановка каналов после смены Wi-Fi/Ethernet, поведение после resume из сна, таймауты) **не проверен**: требует запуска клиента и наблюдения.

## 12. Техническая гипотеза устройства

### Подтверждено

1. **Виртуальный адаптер — L2 Ethernet, не L3/TUN.** INF: `Characteristics = 0x1 ; NCF_VIRTUAL`, `*IfType = 0x6 ; IF_TYPE_ETHERNET_CSMACD`, `*MediaType = 0x0 ; NdisMedium802_3`, `*PhysicalMediaType = 14`, `UpperRange = "ndis5"`, `LowerRange = "ethernet"`. Драйвер `RvNetMP60.sys`, загружается в группе `NDIS`. → Транспорт переносит **Ethernet-кадры**, а не IP-пакеты. **[П]**
2. **Адаптер фигурирует в UI.** В клиенте есть столбец «Network Adapter» рядом с участником; штатное имя адаптера — `Famatech Radmin VPN Ethernet Adapter` (официальный help). Тот факт, что на каждую сеть создаётся отдельный экземпляр адаптера, — **[Г]**: прямо подтверждён только вывод этого поля в интерфейсе. **[П-стр]**
3. **Два уровня: служба + GUI.** `RvControlSvc.exe` под LocalSystem держит драйвер и каналы; `RvRvpnGui.exe` — только интерфейс, общается со службой (отсюда статус «Service connection lost» и кнопка запуска службы). **[П]**
4. **Центральный сервер координации существует.** Строки «Cannot connect to ROL server», «ROL protocol error», библиотека `RvROLClient.dll` с API `ROLClient_Connect`, `ROLClient_ManageNetwork`, `ROLClient_ChatCommand`, `ROLClient_CheckUpdates`. «ROL» — сервис Radmin Online: он ведёт учёт сетей, участников, прав и, судя по API, чат и лицензии. **[П]** для наличия, **[Г]** для точного распределения функций.
5. **Прямой канал + TCP-релей.** Классы `CDirectEnetConnector`, `CENETConnector`, `CTcpInConnector`, `CTRSConnector`, `CUniversalConnector`; в UI — «Direct»/«Relay», в службе — `TcpRelay`. **[П]**
6. **Адресное пространство 26.0.0.0/8**, конфликты и перевыдача адреса обрабатываются клиентом. **[П]**
7. **Управляющий канал, вероятно, TLS** (OpenSSL 3 + libcurl в поставке). **[П]** для библиотек, **[Г]** для протокола.

### Предположение (требует проверки)

- **Протокол данных проприетарный** поверх UDP (ENet-подобный: надёжная доставка, свои sequence/ack) с шифрованием AES-256; при недоступности UDP — инкапсуляция в TCP к релею. Основание: имена коннекторов + заявление о end-to-end AES; прямых доказательств формата кадра нет. **[Г]**
- **Роль координатора**: выдача виртуального IP и маски, хранение состава сети и ролей, обмен «внешними» адресами/портами участников для пробивания NAT (STUN-подобная функция), разрешение на релей. Это минимально необходимый набор, следующий из наблюдаемых функций; конкретные сообщения протокола неизвестны. **[Г]**
- **STUN/TURN-серверы собственные**, не стандартные; строка `CTRSConnector` может означать «Transport Relay Server». **[Г]**
- **Один виртуальный адаптер на сеть** означает: несколько сетей = несколько адаптеров и несколько подсетей внутри 26/8; маршрутизация между сетями не выполняется. **[Г]**

## 13. Что осталось непроверенным

| Вопрос | Почему не закрыт | Как проверять |
|---|---|---|
| Максимум сетей на пользователя (число) | Не опубликован; есть только текст ошибки | Запустить клиент, создавать сети до появления «The virtual network limit has been reached» |
| Порты координатора и релея | Не документированы | `netstat`/Wireshark на живом клиенте при старте и в режиме Relay |
| Стабильность IP между сессиями | Косвенные признаки (renew/conflict) | Перезапуск клиента и смена сети, сравнение адреса |
| Поведение при сне/смене сети | Только наличие класса `CNetworkChanges` | Гибернация + смена Wi-Fi→Ethernet, замер времени восстановления |
| Обязательна ли регистрация аккаунта | В UI есть «Registration…», «Profile» | Установка на чистую машину, попытка создать сеть без входа |
| Ограничение скорости | Официальных цифр нет | iperf3 между двумя узлами |
| Формат кадра и шифрование | Проприетарный протокол, EULA запрещает reverse engineering | Не проверять; для своей реализации проектировать независимо |

## 14. Что из этого переносится в нашу спецификацию (MVP 2–10 узлов)

Обязательный минимум, вытекающий из подтверждённых функций:

1. Сеть = имя + пароль; создание и вход по этим двум полям; роль создателя — администратор.
2. Виртуальный L2-адаптер (TAP-подобный, NDIS 6) на каждую сеть; своя подсеть внутри выделенного диапазона; MAC на адаптер.
3. Координатор: реестр сетей/участников/ролей, выдача IP, обмен endpoint-ами, сигнализация для пробивания NAT.
4. Прямой UDP-канал с heartbeat и метрикой задержки; TCP-релей как резерв с явной индикацией «Relay» у участника.
5. Служба Windows (LocalSystem) + GUI с треем; автозапуск свёрнутым через Run-ключ; состояние «служба не запущена» с кнопкой запуска.
6. Инвариант «в сети всегда есть администратор»; блокировка участника; лимит участников с явной ошибкой при превышении.
7. Правило firewall только для ICMP из внутреннего диапазона; никаких входящих портов из интернета.

Осознанно **не** берём в MVP: игровые публичные сети, чат, прокси, IPv6, интеграцию с remote control, мультиязычность.
