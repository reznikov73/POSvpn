# Аналоги: кто уже это писал

Все цифры ниже проверены через GitHub API 26 октября 2026 года. Подробные
разборы с ссылками — в `research/analogues.md`, `research/analogues-go.md`,
`research/analogues-l2.md`.

## Главный ответ

**Готового open-source клона Radmin VPN нет.** Ближайшие по UX — Lanemu
(Java, без настоящего hole punching) и n2n (C, без GUI и релизов с 2021).
Всё остальное — либо инфраструктурные mesh-VPN с логином через IdP/CA, либо
проекты на 1–2 звезды, которые нельзя рассматривать как образец.

Это хорошая новость: ниша «скачал, ввёл имя сети и пароль, попал в локалку»
действительно свободна. И плохая: копировать готовое целиком не получится,
решения придётся собирать из трёх источников.

## Три образца и что из них берём

### Headscale — форма сервера

Один Go-бинарник, который хранит сети, узлы и ключи и отдаёт клиенту **карту
сети**: список пиров с адресами, ключами и разрешениями. Клиент не
договаривается с другими клиентами — он исполняет выданную карту.

Что копируем: сервер как единственный источник правды, версионирование карты,
выдача IP сервером, хранение только хешей ключей.

### NetBird — разделение плоскостей

Management (кто в сети и с каким IP), Signal (обмен кандидатами, состояния не
хранит), Relay (передача трафика, когда P2P не встал). Три сервиса могут жить
в одном бинарнике, но логически обязаны быть разделены — иначе релей начнёт
участвовать в согласовании.

Что копируем: это разделение и правило «сначала прямой канал, релей не
отключаем». Не копируем код: серверные каталоги NetBird под AGPL-3.0.

### Nebula — структура компактного кода

MIT, один бинарник, читаемая раскладка пакетов, Wintun в зависимостях,
идентичность в сертификате. Хороший пример того, как выглядит аккуратный
Go-проект такого размера.

## Почему не «просто взять готовое»

| Вариант | Что мешает |
|---|---|
| Поднять NetBird/Netmaker | Нужен Docker, DNS, TLS, IdP; сервер AGPL; модель «логин через провайдера», а не «имя сети + пароль» |
| Tailscale + Headscale | Логин через внешний IdP, L3 без бродкаста, GUI для Windows закрыт |
| ZeroTier | Аккаунт и авторизация устройств, контроллер отдельно, L2-драйвер GPL |
| Обернуть готовый движок | Быстро, но ядро чужое: своя адресация, бродкаст и роли всё равно недоступны |

## Свободные ниши

1. **Вход по имени сети и паролю без аккаунта.** Ни Tailscale, ни NetBird,
   ни Nebula так не умеют: везде IdP, CA или контроллер.
2. **L2-семантика.** Из зрелых проектов Ethernet дают только ZeroTier, n2n,
   tinc и SoftEther; остальные — L3.
3. **Порог развёртывания.** Radmin выигрывает не технологией, а тем, что
   ставится за две минуты и не требует сервера у пользователя.
4. **Windows-первый продукт.** Трей, автозапуск, «создать сеть», русский
   интерфейс — редкость в этом сегменте.

## Лицензионная гигиена

- **Можно читать и заимствовать идеи:** Tailscale (BSD-3), Headscale (BSD-3),
  Nebula (MIT), Netmaker (Apache-2.0), innernet (MIT).
- **Только читать:** серверные каталоги NetBird (`management/`, `signal/`,
  `relay/`, `combined/`) — AGPL-3.0; ZeroTier `nonfree/` — source-available.
- **Драйверы:** Wintun — брать официальные подписанные DLL (они под более
  разрешительной лицензией, чем GPL-исходники). `tap-windows6` — GPLv2,
  использовать только как отдельный компонент с соблюдением лицензии.

## Вывод для POSvpn

Формула: **сервер формы Headscale** (один Go-бинарник, карта сети, JSON/SQLite)
+ **разделение плоскостей как в NetBird** (management / signal / relay)
+ **аккуратность Nebula** (маленькие пакеты, читаемый код, MIT-совместимые
  зависимости). Data plane — свой слой кадров поверх QUIC с E2E-шифрованием,
  потому что WireGuard не умеет бродкаст.
