# Функционал: что делает Radmin VPN и что берём мы

Пометки в таблицах: **[П]** — подтверждено официальным источником,
**[П-стр]** — подтверждено строкой/классом внутри клиента, **[Г]** — гипотеза.
Полный разбор с цитатами — `research/radmin-features.md`.

## 1. Что делает Radmin VPN

Radmin VPN — бесплатная программа Famatech для Windows, которая собирает
компьютеры в виртуальную локальную сеть. Сеть создаётся по имени и паролю,
участники видят друг друга как в одном Ethernet-сегменте.

| Функция | Как в Radmin | Статус |
|---|---|---|
| Создание сети | «Create Network», поля «имя сети» и «пароль» | **[П]** |
| Вход в сеть | «Join Network» по имени и паролю, без аккаунта | **[П]** |
| Типы сетей | приватная (по паролю) и игровая (публичная, выбор из списка игр) | **[П]** |
| Участники | список с адресами, статусом, типом канала, адаптером | **[П-стр]** |
| Роли | администратор и пользователь, выдача/отзыв прав, блокировка | **[П-стр]** |
| Управление сетью | переименование, смена пароля, закрытие для новых, удаление | **[П-стр]** |
| Чат | сообщения, ответы, редактирование, жалобы, «печатает» | **[П-стр]** |
| Пинг | из контекстного меню + индикатор из четырёх «палочек» | **[П-стр]** |
| Копирование адреса | IP, IPv6, имя сети | **[П-стр]** |
| Обновления | автоматические | **[П]** |
| Прокси | настройка своего прокси | **[П-стр]** |
| Языки | 100+ переводов | **[П]** |
| Интеграция с Radmin | запуск удалённого управления из списка участников | **[П]** |

**Ограничения**

| Параметр | Значение |
|---|---|
| Цена | бесплатно, без рекламы |
| Участников в приватной сети | 150 ПК, увеличить нельзя |
| Сетей на пользователя | лимит есть, число не опубликовано |
| Адресация | `26.0.0.0/8`; адрес выдаёт координатор, конфликты обрабатываются |
| Канал | «Direct» (UDP) или «Relay/TCP», тип виден в интерфейсе |
| Шифрование | заявлено end-to-end AES-256 (независимо не проверено) |
| Порты | входящие из интернета не нужны |

**Как устроено внутри (подтверждено):** собственный NDIS-драйвер
`RvNetMP60.sys` с `IF_TYPE_ETHERNET_CSMACD` — то есть переносятся
Ethernet-кадры, а не IP-пакеты. Служба `RvControlSvc.exe` под LocalSystem
держит драйвер и каналы, GUI `RvRvpnGui.exe` общается с ней. Есть центральный
сервер координации («ROL server») и TCP-релей.

## 3. Сценарии

**Сценарий А. «Домашний офис».** На работе создают сеть `office` с паролем.
Сотрудник дома ставит клиент, вводит `office` и пароль, получает `10.77.1.3`
и открывает бухгалтерию по адресу `10.77.1.1` — как в локальной сети.

**Сценарий Б. «Игра с другом».** Двое создают сеть `game-night`, один
поднимает сервер игры. Игра ищет сервер в локальной сети. *Работает только
после этапа 4 (бродкаст) или на L2-адаптере.* Для игр с прямым вводом IP
работает уже на этапе 1.

**Сценарий В. «Диагностика».** Администратор смотрит список участников:
кто онлайн, у кого прямой канал, у кого релей, пингует узел из списка.

## 4. Нефункциональные требования

| Требование | Значение |
|---|---|
| Узлов в сети | 2–10 типично, 25 максимум |
| Платформа клиента | Windows 10/11 x64 |
| Платформа сервера | Windows или Linux x64, один процесс |
| Установка | до 2 минут, без перезагрузки |
| Права | после установки GUI работает без администратора; служба — под SYSTEM |
| Память клиента | до 100 МБ в простое |
| MTU туннеля | 1100 байт (кадр ≤ 1180 Б в одной QUIC-дейтаграмме; см. docs/03) |
| Восстановление | после сна/смены сети туннель поднимается сам за 5–10 с |
| Журналы | в `%ProgramData%\POSvpn\logs`, ротация по 10 МБ |
| Секреты | пароли — PBKDF2-SHA256, токены — только хеши, приватные ключи не покидают узел |

## 5. Модель прав и инварианты

1. Создатель сети — администратор. Он может закрыть сеть для новых участников
   и удалить её.
2. **Последний администратор не может покинуть сеть** — иначе сеть останется
   без управления. Проверено тестом `TestHeartbeatAndLeave`.
3. Имя сети уникально без учёта регистра; имя узла уникально внутри сети.
4. Одинаковый ответ на «нет такой сети» и «неверный пароль» — чтобы API нельзя
   было использовать для перебора имён.
5. Заблокированный узел получает 403 на любом запросе.
6. Пароль сети не хранится в открытом виде и не переиспользуется как ключ
   шифрования напрямую.

## 6. Что осознанно не берём в MVP

Игровые публичные сети, чат, прокси, IPv6, интеграцию с удалённым управлением,
автообновление, мультиязычность, биллинг, веб-панель администратора.

Причина одна: каждая из этих функций — отдельный продуктовый слой, а сначала
надо доказать, что туннель работает и им можно пользоваться каждый день.

## 7. Критерии приёмки MVP

1. Два компьютера в разных домашних сетях видят друг друга по внутренним
   адресам: `ping`, общая папка, RDP.
2. Третий компьютер входит по имени и паролю за минуту, без правки роутера.
3. Разрыв связи на 30 секунд не рвёт сессию навсегда: канал восстанавливается.
4. Сервер перезапускается без потери списка сетей и адресов.
5. Установщик ставит программу на чистую Windows 11 без перезагрузки.
6. Тест «выключили Wi-Fi, включили» — туннель вернулся сам.
